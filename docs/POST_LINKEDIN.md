## Texto do post (copie e cole)

Meu cliente perdia leads todo dia no WhatsApp. Então eu construí um atendente com IA para ele 🤖

O Diego Sales é Coordenador Comercial de Planos de Saúde e Palestrante Motivacional Premium.
O problema era clássico: dezenas de mensagens repetidas por dia ("qual o horário?", "quanto custa o plano?",
"você faz palestra?") e agendamentos se perdendo no meio das conversas.

O que eu entreguei:

✅ Bot rodando no número comercial REAL dele (conexão via QR Code)
✅ Responde horário, preço e palestras 24h, com boas-vindas automática
✅ Agenda reuniões direto no Google Calendar
✅ Funciona SEM IA paga (modo regras, grátis) ou com Gemini/OpenAI — upgrade sem mexer no código
✅ Ele configura tudo sozinho, sem programar (nome, horários, preços)

Stack: Python · Flask · Evolution API · Google Calendar API · Docker

A lição que fica: automação boa não substitui o humano — tira o trabalho repetitivo da frente dele.
